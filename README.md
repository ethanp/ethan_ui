# ethan_ui

Shared machined-console UI for Ethan's Flutter apps: graphite metal surfaces,
frosted chrome, IBM Plex type, and console signal blue.

```dart
import 'package:ethan_ui/ethan_ui.dart';
```

Product-specific accents (finance teal/gold/housing, deploy status binding)
stay in each app as overlays on top of these tokens.
